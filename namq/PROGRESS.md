### 2) اختبار النموذج (محلي، آلي) — `node namq/tools/verify-prototype.mjs`
محاكاة iPhone 13 في Chromium، تفاعل عبر الواجهة الفعلية. **21/21 ناجح** (`test-output/results.json`).

| الاختبار | الدليل |
|---|---|
| تعديل النص، الخط، اللون، الحجم | حالة المشروع + الخط محمّل (`document.fonts.check`) |
| سحب النص + التقاط خط المنتصف | (540,1500)→(700,1640) ثم x=540 |
| تراجع · إرجاع الأصل · إضافة نص · إخفاء اختياري | ناجح |
| نص طويل | يظهر التنبيه ويُمنع التصدير، بلا قص |
| رفع صورة + تكبير 180% + تحريك داخل الإطار | zoom=1.8, ox=100, oy=-40 |
| PNG | 1080×1920 RGB، 921 ك.ب — فُتح وروجع بصريًا: الحروف العربية متصلة وسليمة |
| PDF | صفحة واحدة 810×1440pt (=1080×1920px)، PDF 1.4 — حُوّل لصورة وقورن بالـPNG: فرق متوسط ≈2/255 (ضغط JPEG) |
| MP4 | H.264 · yuv420p · 1080×1920 · 30fps · 120 إطار · 4.0ث · بلا صوت — إطار الثانية 3.2 قورن بـPNG المشهد المرجعي: فرق ≈2.5/255 |

**حدود صريحة:**
- MP4 أُنتج هنا بسكربت خادمي (إطارات النص من نفس دالة الرسم + ffmpeg). **لا يوجد خادم تصدير مربوط بالموقع بعد**؛ زر MP4 في الموقع معطّل ومسمّى بذلك.
- PDF صورة نقطية RGB داخل صفحة — ليس ملف طباعة (لا CMYK، لا نزيف، لا خطوط متجهة).
- الخلفية والفيديو والصورة أصول **تجريبية** مولّدة بالكود؛ فيديو الخلفية 540×960 مكبَّر. الخطوط Tajawal/Amiri/Aref Ruqaa/Reem Kufi (رخصة OFL).
- الاختبار على Chromium فقط؛ Safari/iOS الحقيقي لم يُختبر.
- غير منفَّذ بعد في النموذج: الشعار، رمز العروسين، تحريك/تحجيم الإطار، أكثر من صورة، محرّر الإدارة.

### 5) قرارات مطلوبة من المالك قبل المتابعة
1. ترقية الموقع إلى Premium (Core+) وربط Stripe بحساب المنشأة — شرط لأي اختبار دفع.
2. قبول البريد الإلكتروني في الشراء (إجباري في Wix) أو اعتماد دفع مخصص خارج صفحة Wix.
3. بدء الاشتراك بالبطاقة فقط (قيد Wix) أو مسار مخصص.
4. خدمة تصيير MP4 وتخزين الملفات.
5. إبقاء رابط الموقع التجريبي يعمل أو إيقافه.

### الخطوة التالية (بلا قرارات مالية)
تحويل المنتجات التجريبية إلى رقمية، ربط المحرّر بمنتج محدد، إضافة الشعار ورمز العروسين وتعدد الصور، وبدء محرّر الإدارة.
